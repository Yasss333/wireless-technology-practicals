# Experiment 02 - Bluetooth Personal Area Network

Open the .pkt in Cisco Packet Tracer 9.0. PC0 is paired with an IoT appliance (IoT0) and a Bluetooth speaker (IoT1). The appliance broadcasts a Bluetooth beacon every 10 seconds.

To repeat the test, check PC0 > Desktop > Bluetooth for both devices marked **Paired, Connected**. In Simulation mode, enable Bluetooth events and use Capture/Forward. The beacon from IoT0 was observed at PC0 and IoT1.
