# Experiment 01: Wireless LAN

Open the project in Cisco Packet Tracer 9.0. It uses a WRT300N router, two laptops with WPC300N adapters, and one wireless desktop PC. The SSID is `WLAN-Network` with WPA2-PSK (AES). The router provides IPv4 addresses through DHCP on `192.168.0.0/24`.

Packet Tracer reported successful ICMP tests from Laptop0 to Laptop1 and PC0. To repeat the tests, check each client's DHCP address in Desktop > IP Configuration, then ping the other clients using those addresses.
